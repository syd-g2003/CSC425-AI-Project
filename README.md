# CSC425-AI-Project

Team members: Mbaye Cisse and Sydney Gilson.
<br>
Our project is about voice synthesis using AI. We will use datasets with sample voices and the XTTS-v2 python library to replicate a specific voice so that it is able to read user provided text. in addition, we will analyze the efficiency and accuracy of our AI algorithm under different length and qualities of provided input audios, and determine whether preprocessing of input audios improve the results. 
<br>
One dataset we can use is VoxCeleb Voice Gender dataset. It contains 7000+ short voice recordings taken from job interviews, split into male and female. They cover a variety of ages, languages, and accents.
