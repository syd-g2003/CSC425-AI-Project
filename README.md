# CSC425-AI-Project

Team members: Mbaye Cisse and Sydney Gilson.
<br>
Our project is about voice synthesis using AI. We will use datasets with sample voices and make a program using Python that will be able to replicate a specific voice so that it is able to read user provided text. We will use factors such as tone, accent, pitch, age, and others to preserve the properties of the input voice.
<br>
One dataset we can use is VoxCeleb Voice Gender dataset. It contains 7000+ short voice recordings taken from job interviews, split into male and female. They cover a variety of ages, languages, and accents.
